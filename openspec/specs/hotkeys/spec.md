# hotkeys Specification

## Purpose
定义可自定义快捷键的契约：动作目录与默认键位、改键与持久化、冲突处理，以及播放窗口（键盘 + 滚轮）与列表页（搜索框聚焦、上下翻屏、翻页）的实际行为。设置页的呈现归 settings-ui，本能力定义"键位从哪来、怎么改、怎么生效"。

## Requirements

### Requirement: 单一键位来源
键位 MUST 来自一个共享的 QML 单例 `Hotkeys`（`app/qml/Hotkeys.qml`，模块 `bbhouse`），播放窗口、主窗口与设置页 MUST 都从它读取，MUST NOT 各自硬编码按键。单例 MUST 暴露：动作目录（id / 作用域 scope / 可本地化的标签与说明 / 默认键码与修饰键）、作用域清单、键名↔键码表、以及解析与命中查询方法。

#### Scenario: 三处共用一份键位
- **WHEN** 用户在设置页把"音量 +"从 `Up` 改成 `P`
- **THEN** 播放窗口立即改用 `P` 调高音量，原 `Up` 不再触发该动作；主窗口与设置页展示的也是同一份值

#### Scenario: 目录与分组
- **WHEN** 设置页读取单例的动作目录
- **THEN** 得到按作用域分组的全部动作：播放器（音量加减、快退、快进/长按倍速、播放暂停、全屏、静音、弹幕、字幕、下一集）与列表页（聚焦搜索框、上一页、下一页、上翻一屏、下翻一屏）；同组内默认键位互不重复

### Requirement: 组合键表示与命中判定
键位 MUST 以可读字符串持久化与展示（修饰键 `Shift`/`Ctrl`/`Alt`/`Meta`，以 `+` 连接主键名，如 `Ctrl+F`、`Shift+N`、`Up`）。命中判定 MUST 按作用域隔离：同一按键在不同作用域 MUST NOT 互相干扰；修饰键比较 MUST 只考虑 `Shift`/`Ctrl`/`Alt`/`Meta`（如小键盘修饰键 MUST 不影响命中）。

#### Scenario: 同键跨作用域
- **WHEN** 用户在列表页按下 `D`
- **THEN** 触发"列表下翻一屏"，MUST NOT 触发播放器的"弹幕开关"

#### Scenario: 修饰键必须完全匹配
- **WHEN** "播放下一集"绑定为 `Shift+N`，用户只按 `N`
- **THEN** 不触发任何播放器动作

### Requirement: 改键与持久化
设置页 MUST 允许逐条改键（点按按键框后按下目标键即完成，Esc 取消）与逐条恢复默认，并提供"全部恢复默认"。改键 MUST 立即生效并立即持久化；持久化 MUST 走 `AppPreferences` 的通用键值口（整块 JSON 存于单一键 `hotkeys`），MUST NOT 要求重启。仅"可分配按键表"内的按键可被录入；表外按键（如 `Esc`）MUST 被拒绝并给出可本地化提示。偏好数据缺失、部分缺失或不可解析时 MUST NOT 抛错，MUST 回落到默认值。

#### Scenario: 改键即时生效并保存
- **WHEN** 用户点按某动作的按键框并按下 `Ctrl+J`
- **THEN** 该行显示 `Ctrl + J`，对应窗口立即按新键响应；重启应用后仍为 `Ctrl + J`

#### Scenario: 拒绝不可分配按键
- **WHEN** 用户在录入状态按下 `Esc`
- **THEN** 取消本次录入并恢复原键位；若按下的是可分配表外的其他键，则保留原键位并提示该键不可用

#### Scenario: 数据损坏不致命
- **WHEN** 偏好里的 `hotkeys` 值为无法解析的 JSON
- **THEN** 全部动作使用默认键位，应用正常启动

### Requirement: 冲突处理
同作用域内两个动作解析到同一组键时 MUST 可被识别：设置页 MUST 在该行显示可本地化的重复提示；应用 MUST 保持确定性行为（按目录顺序只有靠前的动作生效），MUST NOT 出现未定义行为。

#### Scenario: 改出重复键
- **WHEN** 用户把"音量 +"改成与"静音切换"相同的键
- **THEN** 设置页提示两者重复，实际只有目录中靠前的那个生效，两个动作仍可通过改键分开

### Requirement: 播放窗口键盘快捷键
播放窗口 MUST 支持下列动作，键位取自单例：音量增大/减小（默认 `Up`/`Down`）、快退（默认 `Left`）、快进（默认 `Right`）、播放暂停（默认 `Space`）、全屏切换（默认 `F`）、静音（默认 `M`）、弹幕开关（默认 `D`）、字幕开关（默认 `S`）、播放下一集（默认 `Shift+N`）。`Esc` MUST 固定为逐级退出（全屏 → 最大化 → 窗口 → 关闭），MUST NOT 可改键。音量 MUST 钳制在 0–100。焦点落在消费按键的控件（弹出菜单、播放列表、按钮）上时，对应按键 MUST 由该控件优先处理。

#### Scenario: 音量与进度
- **WHEN** 播放中用户按 `Up` / `Down`
- **THEN** 音量按设定步长增减，且不越过 0 或 100
- **WHEN** 用户按 `Left`
- **THEN** 播放位置按设定步长后退

#### Scenario: 快进键的双用途
- **WHEN** 用户短按 `Right`
- **THEN** 播放位置按设定步长前进，倍速不变
- **WHEN** 用户按住 `Right` 超过设定判定时间
- **THEN** 进入设定倍速播放（默认 2.0×）并提示；松开后 MUST 恢复到按住之前的倍速

#### Scenario: 步长与长按参数可调
- **WHEN** 用户在设置页把快进步长改为 15 秒、长按倍速改为 3.0×
- **THEN** 短按快进按 15 秒推进，长按进入 3.0× 倍速

### Requirement: 播放画面滚轮调节音量
播放窗口的画面区 MUST 支持鼠标滚轮调节音量：上滚增大、下滚减小，步长与方向键音量一致。该行为 MUST 可关闭。滚轮落在播放列表面板上时 MUST 仍用于滚动列表，MUST NOT 改变音量。直播播放窗口 MUST 同样支持。

#### Scenario: 画面区滚轮
- **WHEN** 用户在画面区上滚
- **THEN** 音量增加一档并显示控制栏

#### Scenario: 关闭后不使用滚轮
- **WHEN** 用户在设置页关闭"滚轮调音量"
- **THEN** 画面区滚轮不再改变音量

### Requirement: 列表页快捷键
主窗口 MUST 支持：聚焦搜索框（默认 `Ctrl+F`）、上一页（默认 `K`）、下一页（默认 `J`）、上翻一屏（默认 `U`）、下翻一屏（默认 `D`）。翻页与滚屏 MUST 只在"带分页的页面"生效（特别关注、稍后再看、番剧、流行、本地历史、下载管理）；非分页页面 MUST NOT 响应。焦点落在文本输入控件上时，全部列表页快捷键 MUST 被禁用。翻页 MUST 沿用各页既有分页语义并尊重边界（已在首页/末页时不动）；滚屏 MUST 按视口高度滚动并尊重边界。

#### Scenario: Ctrl+F 直接进入搜索
- **WHEN** 用户在带搜索框的页面按 `Ctrl+F`
- **THEN** 光标直接落到该页标题栏搜索框并选中已有文字，用户可直接输入

#### Scenario: 输入时不抢按键
- **WHEN** 焦点在搜索框或任意文本输入框内，用户输入 `j`、`k`、`u`、`d`
- **THEN** 字符正常输入，不触发翻页或滚屏

#### Scenario: 非分页页面不响应
- **WHEN** 用户在动态、直播、在线历史等无分页页面按 `J` / `K` / `U` / `D`
- **THEN** 不发生翻页或整屏滚动，页面自身滚动仍可用

#### Scenario: 翻页边界
- **WHEN** 用户在分页页首页按 `K`，或在末页按 `J`
- **THEN** 页码不变，不发出越界请求
